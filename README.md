# FeelTech International 👋

> **Solutions technologiques innovantes pour votre transformation numérique.**
> Ingénierie logicielle full-stack — Douala, Cameroun 🇨🇲

Je conçois et déploie des **plateformes métier de bout en bout** : de la base de données
sécurisée jusqu'à l'application web/mobile en production, en passant par le CI/CD. Mon
terrain de jeu : les **SaaS multi-tenants**, les **ERP** (RH & paie, finance, gestion
scolaire, contrôle d'accès) et tout ce qui exige **fiabilité, sécurité et passage à
l'échelle**.

---

## 🧠 Domaines d'expertise

- **Génie logiciel** — architecture applicative, patterns d'état, code maintenable, offline-first.
- **SaaS multi-tenant** — isolation stricte des données par client, control plane / provisioning, exercices comptables.
- **Sécurité applicative** — Row Level Security (RLS) multi-couches, MFA/TOTP, chiffrement au repos, gestion des secrets, moindre privilège.
- **Bases de données** — PostgreSQL & PL/pgSQL, modélisation, migrations versionnées, triggers, RPC.
- **DevOps / CI-CD** — pipelines GitHub Actions (tests → build → déploiement gated), déploiement Vercel, Docker.
